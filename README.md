# Hrishi Tours & Travels - Web Platform

A modern, responsive web application for **Hrishi Tours & Travels** (+91 7908******) with dual **User Portal** and **Admin Management Dashboard**.

## 🌟 Highlights
- **User Portal**: Himalayan Emerald & Sunrise Gold aesthetic, day-by-day itineraries, instant mountain cab fare estimator, custom trip builder, and direct WhatsApp booking.
- **Admin Dashboard**: Real-time KPI metrics, package CRUD manager, lead management with 1-click WhatsApp follow-ups, cab fleet rate editor, and CSV export.
- **Persistence**: Real-time `localStorage` state management with automatic live UI synchronization.

## 🚀 Quickstart
Open `index.html` directly in any web browser, or launch a local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

- **Admin Portal Access**: Click the discreet lock icon (`🔒`) at the bottom of the page, or press `Ctrl + Shift + A` anywhere. Passcode: `admin123` (or click *⚡ 1-Click Quick Demo Access*).
