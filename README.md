## 🌟 Core Modules & Functionality

### 1. 🌐 Full Modern Website & Brand Identity
* **Tailored Himalayan Aesthetic**: Premium Himalayan Emerald (`#064e3b`, `#0d9488`) and Sunrise Gold (`#f59e0b`) palette reflecting the beauty of Sikkim and North East India.
* **100% Responsive on Every Screen**: Optimized for all smartphone aspect ratios (iPhone, Samsung Galaxy), iPads/Tablets, and Desktop monitors.
* **Official Branding**: Integrated circular hiker badge logo (`HT&T.jpeg`) on header, footer, contact badge, and admin panels.
* **Direct Social & Founder Link**: Verified brand badges, clickable founder attribution redirecting to the official Facebook page, and direct WhatsApp links.
* **SEO & Social Share Ready**: Pre-configured Schema.org `TravelAgency` structured data and OpenGraph tags so links display rich cards when shared on WhatsApp, Facebook, or Instagram.

---

### 2. 🎒 Tour Packages Showcase & Interactive Itineraries
* **Multi-Destination Coverage**: Pre-loaded with signature itineraries for **Sikkim**, **Old Silk Route (Zuluk)**, **Darjeeling**, **Dooars**, **Offbeat Homestays (Lepchajagat & Sittong)**, and **Meghalaya**.
* **Filter Pills & Real-time Search**: Visitors can instantly filter packages by destination or trip duration with zero page reloads.
* **Interactive Day-by-Day Itinerary Modal**:
  - Detailed day-wise schedule (morning to evening breakdown).
  - Clear checkmark lists for **Inclusions** (deluxe homestays, meals, mountain driver) and **Exclusions** (permits, adventure sports).
* **1-Click WhatsApp Booking**: Each package has a dedicated booking trigger that opens WhatsApp with the package name and pricing pre-filled.

---

### 3. 🚖 Mountain Cab Fleet & Instant Fare Estimator
* **Verified Mountain Fleet Showcase**: Highlighting rugged 4WD SUVs (Scorpio / Bolero), luxury family carriers (Innova Crysta), hill sedans (Swift Dzire), and group carriers (Tempo Traveller).
* **Interactive Cab Fare Calculator**:
  - Instant transparent pricing for popular routes: NJP Station / Bagdogra Airport (IXB) to Gangtok, Darjeeling, Zuluk, Pelling, and Lataguri.
  - Dynamic vehicle-type calculation with toll, driver allowance, and fuel inclusions clearly displayed.
  - 1-Click WhatsApp Cab Reservation button with route and selected car model pre-populated.

---

### 4. 📋 Lead Capture & Custom Trip Builder
* **Custom Itinerary Request Form**: Captures full traveler details—Name, Phone, Destination, Travelers count, and Travel Date.
* **Dual-Action Conversion**:
  1. Instantly saves the customer inquiry directly into the Admin Lead CRM.
  2. Generates a formatted WhatsApp message launching directly to the business number for immediate chat follow-up.
* **Permit & Safety FAQ Accordion**: Addresses traveler concerns about Sikkim Restricted Area Permits (RAP/PAP), cancellation policies, and road safety.

---

### 5. ⚙️ Stealth Business Admin Panel (CMS)
To protect your business from unwanted tampering, the admin portal is protected by **Stealth Access Security**—it does not display an obvious "Admin" button in the public header:

* **Access Methods**:
  - Click the discreet, low-contrast lock icon (`🔒`) in the footer copyright line.
  - Or press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> on any page.
  - **Demo Passcode**: `admin123` (or click *⚡ 1-Click Quick Demo Access*).
* **Executive Real-Time KPIs**: Counters for Total Enquiries, New Unhandled Leads, Active Packages, Fleet Count, and Estimated Pipeline Revenue.
* **Customer Leads CRM**:
  - Tabular view of all incoming inquiries with timestamps and traveler requirements.
  - 4-Stage Lead Status Switcher (`New` 🔵, `Contacted` 🟡, `Confirmed` 🟢, `Cancelled` 🔴).
  - **1-Click "WhatsApp Customer"**: Initiates a personalized follow-up chat with the client's name pre-written.
  - **Export to CSV**: One-click download of all leads into a CSV file ready for Microsoft Excel or Google Sheets.
* **Tour Packages CRUD Manager**: Add new tour packages, edit pricing, update day-wise schedules, toggle "Featured" status, or delete outdated trips live without touching code.
* **Cab Fleet Rates Editor**: Update daily vehicle rental rates live on the website.
* **Announcement Bar Controller**: Update top banner announcements (festive discounts, seasonal alerts) or toggle banner visibility with one switch.

## 🚀 Quickstart & Local Testing

You do not need to install complex dependencies, databases, or build pipelines.

1. **Direct Browser Launch**:
   Simply double-click `index.html` in your file explorer to open it in Google Chrome, Microsoft Edge, or Safari.

2. **Or via Local Web Server (Recommended)**:
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
   Open [http://localhost:8000](http://localhost:8000) in your browser.

## ☁️ Deployment Instructions (Render)

This repository includes a pre-configured [`render.yaml`](render.yaml) file for automatic cloud deployment.

1. Create a free account at [Render.com](https://dashboard.render.com/).
2. Click **New +** → **Static Site**.
3. Select your GitHub repository: `Demo_Pitching_Website-HT-T-`.
4. Leave **Build Command** empty, set **Publish Directory** to `.`, and click **Create Static Site**.
5. Your live website URL with a free SSL certificate (`https://your-site.onrender.com`) will be active in under 1 minute!
